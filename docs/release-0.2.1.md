# JAX4J 0.2.1

JAX4J 0.2.1 corrects the Java namespace to `com.nablatensor.jax4j` across every module, including generated JIT classes, service descriptors, examples and documentation. Update application imports when upgrading; this is a source and binary incompatible package migration. Maven coordinates remain `com.nablatensor`.

- All seven modules build with Java 25; ordinary and Vulkan/wgpu hardware test suites pass: 126 checks passed, 8 skipped, zero failures/errors. Vulkan passed 31 checks and wgpu passed 36.
- CUDA compiles, but execution could not be revalidated: no local CUDA driver and the previous validation host was unreachable. ROCm and SIMD execution also remain unverified.
- Sources and signed Javadoc artifacts are generated by the committed `central-artifacts` profile. Javadoc omits bundled fonts.
- Native GPU libraries are not bundled. Use `--enable-native-access=ALL-UNNAMED`; SIMD additionally requires `--add-modules jdk.incubator.vector`.
- Existing engine limitations are unchanged: CUDA scalar replay rejects multi-output tapes, uniform draws and named random streams.

Build from the tag with `mvn -Pcuda,rocm,examples,simd clean verify`. Applications normally depend on `com.nablatensor:jax4j-core:0.2.1` plus the desired engine modules; the parent `jax4j` artifact is a POM. Examples are GitHub-only. SHA256SUMS covers all seven binary JARs.

Generate signed source/Javadoc artifacts with `mvn -Pcuda,rocm,simd,central-artifacts verify`. The committed publication profile preserves GPG signing and uses JDK 25 `--no-fonts`.
